# 🌾 AgriMart

AgriMart is a web-based agricultural marketplace that connects farmers and buyers through a simple and user-friendly platform. The application enables farmers to showcase agricultural products while allowing customers to browse and purchase fresh produce efficiently.

## 🚀 Features

* Farmer Registration and Login
* Customer Registration and Login
* Product Listing and Management
* Product Search and Browsing
* Shopping Cart Functionality
* Order Management
* Responsive User Interface
* Secure Authentication

## 🛠️ Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript
* Bootstrap

### Backend

* Python
* Flask

### Database

* SQLite / MySQL

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/jahnavi2005-abc/AgriMart.git
```

2. Navigate to the project directory

```bash
cd AgriMart
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```

5. Open your browser and visit

```text
http://localhost:5000
```
